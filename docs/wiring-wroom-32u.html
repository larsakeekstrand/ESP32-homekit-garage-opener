Rewiring to the ESP32-WROOM-32U (38-pin)

Your firmware addresses pins by GPIO number, not by position on the board — so every assignment is identical to your old 30-pin module. Only the physical location of each pin moves. To rewire: find the header pin whose silk label matches the IO-number below, and land the wire there. No firmware change, no reflash-for-hardware.

Connection table

Function GPIO Board pin Connects to Notes
Door relay GPIO5 IO5 Relay module IN Pulsed ~300 ms to kick the door. Relay VDD → 5V, relay GND → GND. The old prototype has a 20 kΩ (R3) from GPIO5 to GND. The rev 1 PCB (hardware/garage-opener-pcb) drives the relay through a transistor with a 4.7 kΩ pull-down so it cannot click during boot.
Reed door sensor GPIO4 IO4 Reed switch, other leg → GND Internal pull-up is enabled in firmware — no external resistor. Any-edge interrupt, ~50 ms debounce.
Running LED GPIO2 IO2 LED (+) via ~330 Ω → GND On while firmware runs. Strapping pin — an LED load is safe (unchanged from old board).
Door-state LED GPIO16 IO16 LED (+) via ~330 Ω → GND Mirrors door open/closed. On WROOM-32U (no PSRAM), IO16 is free.
DHT22 / AM2301 GPIO22 IO22 Sensor DATA Sensor VCC → 3V3, GND → GND. Old board used no separate data pull-up, so reuse the same DHT22 module (it has its own).
Reset / factory button GPIO0 IO0 On-board “Boot” button (already wired) Short-hold ≈ 3 s → Wi-Fi reset; long-hold ≈ 10 s → factory reset. External button optional, in parallel to GND.
Power in — 5V (bottom-left) +5 V supply / USB 5 V The board’s regulator makes 3V3 on-board. Never feed 5 V into the 3V3 pin.
Ground — GND (any) Common ground Relay, reed sensor, both LEDs and the DHT all share GND. Several GND pins available.

Power distribution — unchanged from the old board

Everything is still powered through the module: USB 5 V feeds the board, and each peripheral taps the board’s own pins. The 38-pin board’s 5V and 3V3 pins are the exact equivalents of your old board’s Vin and 3v3 — wire them the same way.

5 V rail
USB 5 V (VBUS) → 5V pin → Relay VDD (5 V coil).
Old board: this pin was Vin.
3.3 V rail
On-board regulator → 3V3 pin → DHT22 VCC.
Ample headroom — DHT draws ~1.5 mA.
Ground
Common GND → relay, DHT22, both LEDs, reed switch.
Any GND pin will do.

Power-pin equivalence: Vin → 5V · 3v3 → 3V3 · GND → GND. Powered from USB as before, the relay coil (~70 mA) draws from USB VBUS through the 5V pin — comfortably within a normal USB supply. The 5 V relay must sit on 5V, never 3V3.

Strapping pins

GPIO0, GPIO2 and GPIO5 influence boot mode at power-on. They’re the same pins your old board used, so if it booted reliably, this one will too — keep GPIO0 free to be pulled low only by the Boot button.

External antenna — free signal

The “U” means a U.FL connector instead of a PCB antenna. Fitting a small external antenna can add 5–10 dBm — watch it on the WiFi RSSI log line you just added.

GPIO assignments are authoritative, taken from main/board.h. Component values (LED series resistors, DHT pull-up) are standard wiring practice, not defined by the firmware.
